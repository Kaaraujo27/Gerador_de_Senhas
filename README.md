# 🔐 Gerador de Senhas

Projeto desenvolvido em **Python** para geração de senhas aleatórias utilizando letras, números e caracteres especiais.

## 📌 Sobre o projeto

O programa permite que o usuário escolha a quantidade de caracteres da senha e a quantidade de caracteres especiais que deseja utilizar.

A senha é gerada de forma aleatória utilizando as bibliotecas `random` e `string`.

## 🛠️ Tecnologias utilizadas

* Python 3
* `random`
* `string`

## 🚀 Como executar

Clone o repositório:

```bash
git clone [URL_DO_REPOSITORIO](https://github.com/Kaaraujo27/CalculadoraSimples.git)
```

## 💻 Exemplo

```text
Quantos caracteres sua senha terá? 12
Quantos caracteres especiais ela terá? 4

Senha gerada: aK8@pL2#x9!Q
```
